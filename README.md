# AV Schematic

AV Schematic is a VisuallyJS starter app for designing audiovisual wiring diagrams. Drag devices from the library onto the canvas, connect compatible ports with cables, and select a device or cable to edit its properties. Use **Export DXF** to download the schematic as a CAD drawing.

https://visuallyjs.com/demonstrations/av-schematic
